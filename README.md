# General overview
This directory has the following files:

- camera.py: A file where the initial hsv thresholding was developed and tested
- direction_tello_test.py: File used to test initial connection to Tello Drone
- gate_distance_measurements.py: code use to find distance equivalent so that drone could calculate distance
- tello_gate_program.py: Program with the code that runs the program where the Tello crosses the gate
- gate_completo.png: Test image used to test initial HSV thresholding
- gate_prueba.png: Image used to get gate color
